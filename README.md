# 분수 팡! 대포 탐험대

초등학교 3학년 2학기 분수 문제를 풀고, 적은 대포알로 블록 성을 전부 무너뜨리는 웹 게임입니다.

## 구현 내용

- 12개 스테이지, 3스테이지마다 나무 → 강화 나무 → 돌 → 철 도입
- 대포 뒤에서 정면을 조준하는 입체 표현, 화면 안쪽으로 날아가는 대포알
- 선택한 블록 정면에 명중, 물리 시뮬레이션으로 받침 붕괴와 연쇄 낙하, 누적 손상, 정답 1회당 대포알 1발
- 그림과 문장제, 분자·분모 및 대분수 입력, 선택형, 단계별 힌트
- 시간 제한 없음. 문제를 연 시점부터 정답 제출까지 서버에서 측정
- 자동 별명, 서버 점수 계산, 스테이지별 TOP 100과 내 순위
- 동일 탐험대원의 스테이지별 최고 기록만 저장
- 데스크톱·태블릿·휴대폰 지원, 키보드 블록 선택, 소리 끄기

## 학습 범위

2022 개정 교육과정에 따른 3학년 2학기 분수 학습을 대상으로 합니다. 특정 출판사의 차시 순서를 복제하지 않았습니다.

1~3: 여러 물건을 같은 수씩 묶고 전체와 부분을 분수로 나타내기. 도전 문제는 남은 묶음 생각하기.
4~6: 자연수로 주어진 전체의 분수만큼 구하기. 도전 문제의 남은 양은 자연수 개수의 뺄셈으로 해결.
7~9: 진분수·가분수 구별, 가분수와 대분수 바꾸기.
10~12: 분모가 같은 분수의 크기 비교. 가분수와 대분수를 같은 표현으로 바꾸어 비교.

**출제하지 않는 내용:** 분수의 덧셈·뺄셈·곱셈·나눗셈, 약분·통분 요구, 일반적인 이분모 분수 비교, ‘정답 없음’, 대수식.

분수 답의 동치성은 채점에서만 인정합니다. 예를 들어 4/5 대신 12/15를 입력해도 맞다고 하고, 묶음 기준 설명을 보여 줍니다. 학생에게 약분이나 통분 방법을 가르치거나 요구하지 않습니다.

문항은 제한된 템플릿과 숫자 범위로 생성됩니다. 외부 AI가 실시간으로 문제를 만들지 않습니다. 모든 템플릿은 lib/questions.ts에서 검토할 수 있습니다.

## 점수와 랭킹

### 일관된 물리 규칙

모든 발사는 같은 충격량을 전달합니다. 문제 난이도나 내구도에 따른 발사력 보너스는 없습니다. 블록 질량은 크기와 재질의 밀도로 계산하므로 같은 충격에도 크고 무거운 블록은 덜 움직입니다. 회전도 같은 충격의 작용점과 관성에 따라 계산합니다.

손상은 접촉 마찰만 선형으로 낮춥니다. 단단함이 0이 되는 순간 힘이 커지거나 공기 저항이 바뀌지 않습니다. 중력과 공기 저항은 모든 재질에 동일합니다. 같은 상태에 같은 발사를 하면 같은 결과를 냅니다. 받침을 잃은 블록도 다른 블록이나 선반이 받쳐 주면 남습니다.

초반과 중반은 가벼운 블록으로 조정했습니다. 1~6스테이지의 최대 단단함은 1, 7~11스테이지는 2입니다. 기존의 무겁고 마찰이 큰 설정은 12스테이지의 강화 블록에 적용하며 최대 단단함은 4입니다. 기존 진행 데이터도 새 단단함으로 조정하되 블록 위치, 제거된 블록, 문제, 이미 입힌 손상은 유지합니다. 같은 하단 우선 공략 기준으로 7스테이지는 기존 19발에서 9발로 줄었으며 실제 발수는 공략에 따라 달라집니다.

교육용 게임에 맞춘 2차원 근사 모델이며 실제 재료의 파괴 실험을 재현하는 모델은 아닙니다. 이전 시험 기록과 물리 규칙이 달라졌으므로 정식 전국 랭킹 공개 시에는 새 시즌을 사용해야 합니다.

완료 점수 = 대포알 점수(최대 70,000) + 정확도(최대 20,000) + 속도(최대 10,000).

- 대포알: 70,000 / (1 + (발수 - 1) × 0.25)
- 정확도: 20,000 × 정답 수 / (정답 수 + 오답 수)
- 속도: 문제마다 max(0, 1 - 풀이시간/60초)를 계산하고 평균 × 10,000
- 오답이나 힌트를 사용한 문제의 속도 보너스는 0
- 시간 제한은 없으며, 조준·발사·붕괴 대기 시간은 풀이 시간에 들어가지 않음
- 문제를 열고 다른 탭을 보거나 새로고침한 시간은 포함
- 동점: 발수, 오답, 총 풀이 시간, 먼저 등록한 기록 순

서버가 문제, 정답 판정, 물리 시뮬레이션, 완료 판정, 점수를 관리합니다. 브라우저가 보내는 점수를 받아 저장하지 않습니다. 다른 탐험대원의 진행 기록 사용, 잠긴 스테이지 시작, 정답 없이 발사는 거절합니다. 동시 요청은 버전 검사로 중복 반영을 막습니다.

테스트 시즌: 2026-pilot-1. 자동 풀이 봇 탐지나 사람당 1계정 보장은 아직 제공하지 않습니다. 비로그인 이용자는 보안 쿠키로 브라우저별 식별하며 쿠키 삭제·다른 기기에서는 새 탐험대원이 됩니다. 플랫폼 로그인 이용자는 해당 사이트의 계정 식별자로 연결됩니다. 실명·학교·이메일을 랭킹에 표시하지 않습니다.

## 실행

Node.js 22.13 이상을 사용합니다.

1. npm ci
2. npm run build
3. node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_dashing_rhino.sql
4. npm run dev

3번은 새 로컬 데이터베이스에 한 번만 실행합니다. 미리보기 주소는 실행 시 표시됩니다.

검증: node --experimental-strip-types tests/game.mjs
오디오 종료·재생 오류 재현 검사: node --experimental-strip-types tests/audio.mjs
타입 검사: node node_modules/typescript/bin/tsc --noEmit

정면 발사는 깊이 방향으로 연출하며, 블록의 무너짐은 2차원 물리로 계산합니다. 블록은 내구도가 0이 되어도 삭제되지 않고 충격을 받아 밀리고 회전합니다. 높은 선반 위에 남아 있으면 다시 공략해야 하며, 블록 전체가 선반 아래로 낙하해 화면 하단을 벗어난 뒤에만 성공으로 계산합니다. 받침을 밀어내면 위쪽 블록이 실제 물리 충돌과 중력으로 무너집니다. 첫 애니메이션 콜백의 시간을 기준으로 재생하고 빈 프레임 응답도 최종 게임 상태로 복구합니다.

## 저장과 게시

Cloudflare D1을 사용하는 Sites 백엔드가 포함되어 있습니다. 로컬 데이터와 게시된 사이트의 데이터는 별개이며 테스트 기록은 전국 랭킹에 올라가지 않습니다. 생성된 drizzle 마이그레이션은 게시 과정에서 적용됩니다.

GitHub에는 이 프로젝트의 소스를 보관합니다. **GitHub Pages만으로는 이 서버와 전국 랭킹이 동작하지 않습니다.** 실행은 Sites에서 하고 GitHub는 소스 보관용으로 사용하거나, 별도 Workers 호스팅에 맞게 배포 설정을 구성해야 합니다.

.openai/hosting.json은 이 사이트의 프로젝트 연결 정보이며 비밀 키를 포함하지 않습니다. .env, node_modules, .wrangler의 로컬 데이터는 Git에 포함하지 않습니다.

## 확인한 사항

- 2,880개 문제 생성 조합의 정답 처리와 분수 동치 처리
- 12개 스테이지 모두 실제 물리 시뮬레이션으로 완료
- 브라우저: 오답, 정답, 새로고침 이어 풀기, 발사, 완료, 다음 성, 랭킹 등록
- 잠긴 스테이지·정답 없는 발사·다른 이용자의 기록 사용 거절
- 중복 등록 시 최고 기록 하나 유지, 더 낮은 기록 재등록 시 기존 최고 점수 유지
- 새 브라우저 세션에서 기록 유지, 다른 방문자의 동일 랭킹 조회, 클라이언트가 보낸 점수 무시
- 휴대폰 너비의 가로 넘침 없음

블록 단단함과 점수 배점은 실제 학생 플레이를 거쳐 조정할 수 있습니다. 공개 전국 경쟁을 시작할 때에는 테스트 시즌을 종료하고 새 시즌을 열어 주세요.
