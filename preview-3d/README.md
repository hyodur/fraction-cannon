# 분수 팡! 3D 12단계
기존 앱과 분리된 3D 연습 버전입니다. 전국 랭킹에는 등록하지 않습니다.

## 실행
GitHub Actions의 ZIP 전체를 풀고 `start-3d.cmd`를 실행합니다. 기존 3D 서버를 닫고 새 폴더에서 실행하세요. 주소는 http://127.0.0.1:5174 입니다.
개발: `npm install`, `npm run dev`. 검사: `npm test`, `npm run build`, `npm run test:browser`.

## 단계 설계
|단계|재질|블록 수|주제|
|---|---|---|---|
|1–3|나무|8, 9, 10|전체와 부분|
|4–6|벽돌|11, 12, 13|분수만큼의 양|
|7–9|돌|14, 15, 16|여러 가지 분수|
|10–12|철|17, 18, 20|분수의 크기 비교|

동일 재질의 물리 저항은 일정하며 재질마다 기준 1.00, 1.02, 1.04, 1.06로 완만하게 증가합니다. 기준 밀도 4.38와 블록의 부피에 비례하는 질량에 적용합니다. 재질별 수치는 유지하고 받침 구조를 분리해 난이도를 조절합니다. 같은 재질에서 숫자만 몰래 강화하거나 임의로 블록을 삭제하지 않습니다. 좌우 두 탑은 기둥과 짧은 가로 받침을 각각 갖습니다. 가운데를 가로지르는 공통 받침이 없으므로 한쪽을 무너뜨린 뒤 다른 쪽도 공략해야 합니다. 물리 충돌과 중력은 계속 적용되며 임의로 최소 발사 횟수를 강제하지 않습니다.

단계별로 블록을 1~2개 추가합니다. 1단계의 독립된 작은 탑 두 개 → 2~3단계의 넓어진 윗부분 → 4~5단계의 위층 → 6단계 가운데 조각 → 7~10단계 양옆 작은 탑 → 11단계 가운데 위층 → 12단계 징검 조각 순서입니다. 작은 곁다리 탑은 두 층까지만 쌓습니다. 선반의 표시 폭과 물리 충돌 폭을 함께 5.4로 넓혔습니다.
실제 필요한 정답/발사 횟수는 조준과 연쇄 붕괴에 따라 달라집니다. 회귀 검사에서는 같은 공략 순서로 전 단계를 완주하고 뒤쪽 단계의 풀이량이 앞쪽보다 늘어나는지 확인합니다.

같은 주제의 세 단계에서 분모 상한 4→5→7, 묶음 크기 상한 3→4→5, 대분수 자연수 부분 상한 1→2→3으로 점진적으로 늘립니다. 새로운 주제의 첫 단계에는 가능한 문제에 그림 도움을 제공합니다. 비교 문제는 분모가 같은 분수만 사용하며, 통분·약분·분수의 사칙연산은 출제하지 않습니다. 대분수와 가분수는 세로 분수 형태로 표시합니다.
참고: [아이스크림 수학 3-2 지도서](https://qrd.i-scream.co.kr/22USB/22MA302/index.html). 기존 게임에서 합의한 분수 내용 범위를 유지합니다.

## 진행과 완료
한 단계 성공 후 다음 단계가 열립니다. 완료 단계와 현재 선택 단계는 브라우저에 저장합니다. 진행 중 물리 상태는 저장하지 않습니다. 저장이 불가능한 경우 화면에 안내하고 플레이는 계속됩니다.
블록 전체가 선반 아래로 내려가면 낙하 완료로 판정합니다. 잔해는 계속 보이고 움직이지만 다시 선택하거나 공격할 수 없습니다. 마지막 블록이 떨어지면 즉시 성공합니다.

## 검증
좌우 받침의 넓은 타격 면을 검사하는 90개 독립성 사례, 물리/균형 회귀 검사, 12단계 종료 및 점진성, 3,600개 문제의 독립 계산 검증, 진행 저장 검증, 실제 WebGL 브라우저의 12단계 이동/네 종류 답 입력/마지막 성공/재방문을 검사합니다.

## 정답과 점수
분수는 기대한 분자·분모가 각각 같아야 정답입니다. 예를 들어 정답이 2/3이면 4/6은 인정하지 않습니다. 대분수도 자연수 부분·분자·분모를 각각 확인합니다. 숫자 입력의 앞자리 0이나 바깥 공백은 수의 표현 차이로 허용합니다. 원래 게임의 서버 채점에도 동일한 규칙을 적용합니다.

틀린 답은 같은 문제에서 다시 풀 수 있으며 오답 횟수는 단계가 끝날 때까지 유지됩니다. 빈 답은 제출 안내만 표시하고 오답으로 세지 않습니다.
최종 점수는 성공 1,000점 + 대포알 보너스(최대 600점, 첫 발 이후 한 발당 40점 감소) + 문제 풀이 시간 보너스(최대 200점, 누적 정답까지의 시간 1초당 1점 감소) + 무오답 보너스 200점 − 오답 1회당 150점입니다. 각 보너스와 최종 점수의 하한은 0점입니다. 물리 애니메이션과 목표 선택 시간은 풀이 시간에서 제외됩니다. 제한 시간이나 오답 횟수 제한은 없습니다.

점수 내역은 단계 성공 화면에 표시합니다. 이 연습 버전의 점수는 서버나 전국 랭킹에 저장하지 않습니다. 다시 도전하거나 다음 단계로 이동하면 해당 시도의 오답·발사·시간 기록이 초기화됩니다.
