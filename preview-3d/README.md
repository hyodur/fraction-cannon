# 분수 팡! 3D 12단계
기존 앱과 분리된 3D 연습 버전입니다. 전국 랭킹에는 등록하지 않습니다.

## 실행
GitHub Actions의 ZIP 전체를 풀고 `start-3d.cmd`를 실행합니다. 기존 3D 서버를 닫고 새 폴더에서 실행하세요. 주소는 http://127.0.0.1:5174 입니다.
개발: `npm install`, `npm run dev`. 검사: `npm test`, `npm run build`, `npm run test:browser`.

## 단계 설계
|단계|재질|블록 수|주제|
|---|---|---|---|
|1–3|나무|9, 10, 11|전체와 부분|
|4–6|벽돌|10, 11, 12|분수만큼의 양|
|7–9|돌|11, 12, 13|여러 가지 분수|
|10–12|철|12, 13, 14|분수의 크기 비교|

동일 재질의 물리 저항은 일정하며 재질마다 기준 1.00, 1.08, 1.16, 1.24로 완만하게 증가합니다. 블록의 부피에 비례하는 질량에 적용합니다. 같은 재질에서 숫자만 몰래 강화하거나 임의로 블록을 삭제하지 않습니다. 검증된 중앙 구조와 주변의 작은 더미를 사용합니다.

같은 주제의 세 단계에서 분모 상한 4→5→7, 묶음 크기 상한 3→4→5, 대분수 자연수 부분 상한 1→2→3으로 점진적으로 늘립니다. 새로운 주제의 첫 단계에는 가능한 문제에 그림 도움을 제공합니다. 비교 문제는 분모가 같은 분수만 사용하며, 통분·약분·분수의 사칙연산은 출제하지 않습니다. 대분수와 가분수는 세로 분수 형태로 표시합니다.
참고: [아이스크림 수학 3-2 지도서](https://qrd.i-scream.co.kr/22USB/22MA302/index.html). 기존 게임에서 합의한 분수 내용 범위를 유지합니다.

## 진행과 완료
한 단계 성공 후 다음 단계가 열립니다. 완료 단계와 현재 선택 단계는 브라우저에 저장합니다. 진행 중 물리 상태는 저장하지 않습니다. 저장이 불가능한 경우 화면에 안내하고 플레이는 계속됩니다.
블록 전체가 선반 아래로 내려가면 낙하 완료로 판정합니다. 잔해는 계속 보이고 움직이지만 다시 선택하거나 공격할 수 없습니다. 마지막 블록이 떨어지면 즉시 성공합니다.

## 검증
물리/균형 회귀 검사, 12단계 종료 및 점진성, 3,600개 문제의 독립 계산 검증, 진행 저장 검증, 실제 WebGL 브라우저의 12단계 이동/네 종류 답 입력/마지막 성공/재방문을 검사합니다.
