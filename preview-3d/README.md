# 실제 3D 체험판 · 첫 번째 작전

1스테이지에서 질감과 움직임을 검토하는 별도 체험판입니다. 기존 게임의 진행 데이터와 전국 랭킹을 사용하거나 변경하지 않습니다.

- Three.js: 실제 입체 블록, 나뭇결, 모서리, 금속 대포, 조명과 그림자
- cannon-es: 앞뒤 이동, 세 축 회전, 맞은 위치에 따른 충격, 선반·블록·바닥 접촉
- 120 Hz 고정 물리 시간 간격, 같은 발사에 같은 충격량, 지지와 속도를 확인한 뒤에만 정지
- 선반 아래로 완전히 떨어진 블록만 성공으로 판정, 바닥에 떨어진 블록도 잔해로 유지
- 기존 lib/questions.ts의 1스테이지 문제·채점 사용. 초등 3학년 2학기 범위 유지
- 정답을 맞혀야 발사, 하단 받침은 도전 문제, 힌트 2개, 효과음·음소거
- 번호 버튼으로 키보드 조준 가능, 모바일 배치, WebGL 오류 안내

## 실행
프로젝트의 preview-3d 폴더에서 Node 22.18 이상으로 실행합니다.

```sh
npm install
npm run dev
```

기본 주소: http://127.0.0.1:5174/ (기존 게임의 5173 포트와 구분)

## 검증
```sh
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

GitHub Actions는 물리·문제·타입·빌드·브라우저 검사를 실행하고, 빌드 결과와 화면 캡처 및 생성된 package-lock.json을 결과물로 보관합니다. 정식 전환 전에는 실제 사용 기기의 WebGL 성능, 화면 구도와 타격감을 사람이 확인해야 합니다.

현재 지원 범위는 1스테이지 체험입니다. 전국 랭킹 및 전체 12스테이지 전환은 체험판을 검토한 뒤 서버의 3D 판정과 함께 연결해야 합니다. 이 클라이언트 체험의 결과를 정식 점수로 받아들이면 안 됩니다.
